This folder holds the example project's SLURM job scripts (EXAMPLE_*.sbatch)
and the plotting scripts of its chains, minima and profiles (EXAMPLE_PLOT_*.py
and EXAMPLE_MIN_COMPARE_CONV.py).

In a Cosmolike project, this folder also holds compile_NAME.sh, start_NAME.sh
and stop_NAME.sh, where NAME is the project folder name: the scripts
installation_scripts/compile_all_projects.sh, start_all_projects.sh and
stop_all_projects.sh run them for every project folder except example.
